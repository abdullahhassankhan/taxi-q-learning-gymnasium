# Taxi-v3 Q-learning from scratch

**University assignment:** Custom Reinforcement Learning Agent Implementation using Farama Gymnasium.

- **Environment:** `Taxi-v3` (500 states × 6 actions)
- **Algorithm:** Tabular off-policy Q-learning, epsilon-greedy exploration and per-episode epsilon decay
- **Restrictions:** No Stable-Baselines3 or other RL algorithm libraries.
- **Python:** Use Python 3.11, 3.12 or 3.13.

## Installation (Windows PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

For macOS/Linux use `python3 -m venv .venv`, `source .venv/bin/activate`, and the same two pip commands.

Gymnasium 1.2.3 is intentionally pinned because newer Gymnasium versions introduced Taxi-v4. This project uses the exact `Taxi-v3` requested by the assignment.

## Run

```powershell
python main.py --episodes 15000 --alpha 0.1 --gamma 0.95 --epsilon-start 1 --epsilon-min 0.01 --epsilon-decay 0.9995 --seed 42
python experiments.py --episodes 8000 --seeds 0 1 2
jupyter notebook taxi_rl.ipynb
```

In Jupyter choose **Kernel → Restart & Run All** and save the notebook with its executed outputs. The notebook repeats the analysis and writes its outputs under `outputs/notebook/`.

**Files generated by `main.py`:**

- `outputs/q_table.npy`: trained 500 × 6 Q-table
- `outputs/training_history.npz`: rewards, steps, epsilon histories
- `outputs/training_curves.png`: 3-panel learning curves
- `outputs/evaluation.json`: fixed-seed greedy evaluation metrics and setup
- `outputs/taxi_agent.gif`: an actual successful greedy rollout

**Files generated by `experiments.py`:**

- `outputs/experiments/alpha_comparison.png`
- `outputs/experiments/gamma_comparison.png`
- `outputs/experiments/epsilon_decay_comparison.png`
- `outputs/experiments/experiments_results.csv` (per-seed results)
- `outputs/experiments/experiments_summary.csv` (aggregated mean and SD)

## Notes

- Reproducibility: seeded environment RNG, seeded Q-learning RNG, fixed evaluation seeds. Software/OS differences can still affect exact outputs.
- `terminated` means genuine completion; `truncated` is a time-limit cutoff. Q-learning bootstraps for truncation (which is not an MDP-terminal transition), but stops the episode in either case.
- Training and evaluation use all six actions without action masks, so learning the penalties for illegal actions is part of the assignment.
- GIF rendering needs `pygame` and RGB frames from `render_mode="rgb_array"`.
- If GIF creation reports that no successful episode was found, train for more episodes or reduce the rate of epsilon decay. Do not submit an unsuccessful GIF labeled as successful.
- For headless Linux rendering, try `SDL_VIDEODRIVER=dummy` if pygame cannot create a display.
- For Windows PowerShell script restrictions, use `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` or launch `.venv\Scripts\python.exe` directly.
